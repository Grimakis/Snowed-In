# Snow Day (SNOW.DO)

Driveway shoveling puzzle for the TRS-80 Model 100 in BASIC.

## Run
- Load `SNOW.DO` into Model 100 BASIC.
- RUN

## Controls
- Move: W/A/S/D or arrow keys
- R: restart
- Q: quit to level select

## Notes
- Levels (LV%) change obstacle difficulty.
- Snow mode (SM%) controls snow density.

## Files
- `SNOW.DO`: game source
- `codex_*.md`: design/implementation notes
